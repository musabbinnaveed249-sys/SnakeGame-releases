# SnakeGame

A simple Snake game for Windows, macOS, and Linux.

## Download

Go to the **[Releases](../../releases)** page and download the version for your operating system. The **[Releases](../../releases)** page also includes instructions on handling security warnings on Windows and macOS, due to the game not being digitally signed.

### Windows

[**Download SnakeGame for Windows**](https://github.com/musabbinnaveed249-sys/SnakeGame-Releases/releases/latest/download/SnakeGame-Windows-v1.0.2.zip)

Download the Windows ZIP, extract it, and either:

* Run `SnakeGameSetup.exe` to install the game.
* Run `SnakeGame.exe` to use the portable version.

### macOS

[**Download SnakeGame for macOS**](https://github.com/musabbinnaveed249-sys/SnakeGame-Releases/releases/latest/download/SnakeGame-macOS-v1.0.2.zip)

Download the macOS ZIP, extract it, and move `SnakeGame.app` to your **Applications** folder.

### Linux

[**Download SnakeGame for Linux**](https://github.com/musabbinnaveed249-sys/SnakeGame-Releases/latest/download/SnakeGame-Linux-v1.0.2.zip)

Download the Linux ZIP, extract it, and follow the instructions in `ReadMe-Linux.txt`.

## Current Version

**SnakeGame v1.0.2**

The game includes automatic saving for scores and level progress.

## Important

Windows and macOS may display security warnings because the game is not digitally signed. The release includes instructions for allowing the game to run.

## About

SnakeGame is a standalone game. You do not need any external software to play it.
